# Herald
Animated tab header/footer plus scheduled title, action bar and chat announcements for Paper 1.21+/26.x. MiniMessage & legacy colors, built-in placeholders ({player} {online} {max} {world}), PlaceholderAPI softdepend. Successor in spirit to TitleManager (1.25M downloads, unmaintained since 2021). One jar.
Commands: `/herald` (status) · `/herald reload`
